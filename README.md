# Orvale Desarrollos (demo ficticia)

Demo de sitio web para desarrollos inmobiliarios. **Es un proyecto ficticio de demostración**: la desarrolladora (Orvale Desarrollos) y sus desarrollos (Lumarel Tulum, Obsidia Polanco) no existen. Diseñado y desarrollado por Ricardo Cáceres.

*Fictional demo project — designed and built by Ricardo Cáceres.*

## Stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, zod, vitest. i18n propio en/es con rutas `/en` y `/es`. Preparado para Contentful (`CONTENT_SOURCE`, ver `.env.example`).

## Comandos

- `pnpm dev` — desarrollo
- `pnpm lint` — ESLint
- `pnpm typecheck` — TypeScript
- `pnpm test` — vitest
- `pnpm build` / `pnpm start` — producción
